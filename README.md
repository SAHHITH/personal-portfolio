# Shahith G Portfolio

Welcome to the official portfolio repository of **G Shahith** — AI Engineer & MLOps Developer.

## Overview

A modern, cinematic portfolio showcasing intelligent AI & Machine Learning systems, model deployment architectures, and reliable MLOps pipelines.

## Tech Stack

- **AI & MLOps:** Python, PyTorch, TensorFlow, Generative AI, Docker, Kubernetes, MLflow, FastAPI
- **Frontend & UI:** React, TypeScript, Vite, Tailwind CSS, Framer Motion
- **3D & Visuals:** Three.js, React Three Fiber, Lucide React, React Icons

## Getting Started

1. Install dependencies:
   bash
   npm install

2. Start development server:
   bash
   npm run dev

3. Build for production:
   bash
   npm run build
