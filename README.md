# 🐳 Run with Docker

Build the Docker image:

```bash
docker build -t shahith-portfolio .
```

Run the container:

```bash
docker run -d -p 8080:80 --name shahith-portfolio-container shahith-portfolio
```

Open:

`http://localhost:8080`

Stop the container:

```bash
docker stop shahith-portfolio-container
```

Start it again:

```bash
docker start shahith-portfolio-container
```

---

# 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/SAHHITH/personal-portfolio.git
```

Navigate to the project:

```bash
cd personal-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
